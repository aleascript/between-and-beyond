# Tones

A single **Metaxy** Horizon can support different experiences.

A game may be realistic, epic, dark, dreamlike, satirical, tragic, or use another tone chosen for the campaign. Tone can change presentation, situations and consequences without requiring a different core game.

This page will later provide practical guidance for those variations.
