# Tonalités

Une même déclinaison de **Metaxy** peut produire des expériences différentes.

Une campagne peut être réaliste, épique, sombre, onirique, satirique, tragique ou adopter un autre ton. Le ton peut modifier la présentation, les situations et les conséquences sans exiger un autre socle de jeu.

Cette page proposera plus tard des indications pratiques pour ces variations.
